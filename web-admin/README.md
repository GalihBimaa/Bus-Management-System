# Nusantara Hijau Trans — Web Application (`web-admin`)

Aplikasi web manajemen keberangkatan dan pemesanan tiket bus berbasis **Next.js (App Router)**, **TypeScript**, dan **Tailwind CSS**.

Lihat dokumentasi lengkap fitur, pembagian hak akses (**Pengguna**, **Admin**, **Owner**), serta panduan penggunaan pada file [README.md utama](../README.md).

## Menjalankan Server Development

```bash
npm install
npm run dev
```

Kemudian buka [http://localhost:3000](http://localhost:3000) di browser.
